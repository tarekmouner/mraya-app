# مراية MIRAYA — نسخة تشغيل أولية على Streamlit

هذه الحزمة تجمع صفحة الواجهة الحالية وصورها مع تسجيل الدخول/إنشاء الحساب، ونواة بيانات SQLite والشاشات الداخلية الأولية. **ليست بعد منصة إنتاج مكتملة** ولا تحتوي على اتصالات حية بالذكاء الاصطناعي أو OTP أو الدفع أو الصوت/الفيديو.

## الملفات
- `app.py`: نقطة تشغيل Streamlit، مع الإبقاء على الصفحة التعريفية الحالية.
- `mraya_core.py`: الحسابات، كلمات المرور المشفرة، المحفظة، اليوميات، الجلسات المخزنة، المتجر، الإحالات والبلاغات.
- `mraya_remaining_ui.py`: الشاشات الداخلية الأولية.
- `requirements.txt`: المكتبات المطلوبة.
- ملفات PNG: صور الهوية الموجودة.

## رفعها على GitHub من المتصفح
1. افتح مستودع `mraya-app`.
2. خذ نسخة احتياطية من `app.py` وأي ملفات بيانات قديمة.
3. ارفع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، بجوار `app.py`، واختر استبدال `app.py` و`requirements.txt` عند الطلب.
4. لا ترفع أي ملف أسرار أو كلمة مرور إلى GitHub.
5. في Streamlit Community Cloud افتح تطبيقك ثم **Settings → Secrets** وأضف:

```toml
MIRAYA_OWNER_LOGIN = "tarek"
MIRAYA_OWNER_INITIAL_PASSWORD = "ضع_هنا_كلمة_مرور_طويلة_وفريدة_لا_تستخدمها_في_أي_مكان_آخر"
```

6. اجعل Main file path هو `app.py` ثم أعد تشغيل التطبيق.
7. أول تشغيل ينشئ حساب المالك `tarek` إذا لم يكن موجودًا، باستخدام كلمة المرور التي وضعتها في Secrets. إذا كان الحساب موجودًا بالفعل فلن تُستبدل كلمة مروره تلقائيًا.

## ما الذي يعمل في هذه النسخة؟
- الصفحة التعريفية والصور الموجودة.
- إنشاء الحساب وتسجيل الدخول باستخدام معرف مراية/المعرف العام/البريد أو الهاتف (البريد والهاتف لا يتم توثيقهما برسالة OTP في هذه النسخة).
- تخزين كلمات المرور باستخدام PBKDF2.
- بيانات حساب مستقلة، يوميات خاصة، رصيد كوينز وماسات وسجل محفظة.
- شاشات أولية للجلسات الكتابية التجريبية والمتجر والإحالات والبلاغات وإدارة المالك.

## ما الذي لا يعمل كخدمة حية بعد؟
- جلسات الذكاء الاصطناعي: شاشة الجلسة الحالية تحفظ الرسائل فقط ولا تتصل بموديل ذكاء اصطناعي. يلزم ربط مزود AI ومراجعة سلامة وأزمات قبل إطلاقها.
- OTP واستعادة الحساب: يلزم مزود بريد/SMS وتدفق رموز مؤقتة ومحددات محاولات.
- الصوت والفيديو والجلسات الجماعية: يلزم مزود WebRTC/SFU وتوكنات وصول وموافقة وإشراف؛ Streamlit وحده لا ينشئ مكالمة.
- الدفع والاشتراكات والسحب: يلزم بوابة دفع مناسبة وWebhook موقّع وتسوية ومراجعة قانونية. لا تعتبر تغييرات الرصيد تحصيلًا ماليًا.
- الألعاب ذات الجوائز أو الأرصدة القابلة للاسترداد: لا تفعّلها قبل مراجعة قانونية حسب الدولة.

## تنبيه مهم عن البيانات
قاعدة SQLite المحلية مناسبة لاختبار أولي فقط. نظام ملفات Streamlit Community Cloud ليس قاعدة بيانات إنتاج دائمة وقد تُفقد البيانات عند إعادة إنشاء البيئة أو نقل التطبيق. قبل فتح التسجيل للجمهور، انقل قاعدة البيانات إلى PostgreSQL مُدار (مثل Supabase) مع نسخ احتياطي وصلاحيات وصول مناسبة. لا تضع مفاتيح الخدمة داخل الكود.

## السلامة والخصوصية
مراية أداة دعم نفسي رقمية وليست تشخيصًا أو بديلًا عن اختصاصي مؤهل. لا تُتح للمشرفين قراءة اليوميات أو المحادثات الخاصة افتراضيًا. يلزم إظهار موافقات واضحة قبل أي مشاركة أو تسجيل، وإضافة مسار مساعدة عاجلة مناسب قبل الإطلاق العام.


## صفحات الألعاب المضافة
تمت إضافة `mraya_games.py` وربطها بالقائمة الداخلية. تشمل عجلة تحديات، تحدي ذاكرة، اختبار معلومات، وبوكر تدريبية. النتائج والنقاط تُسجل في جدول مستقل `game_history`، ولوحة ترتيب عامة، ويمكن للمالك تشغيل/إيقاف كل لعبة من «إدارة الألعاب». النقاط ترفيهية فقط ولا تدخل محفظة الكوينز/الماسات. لا توجد رهانات أو مشتريات رقائق أو جوائز قابلة للتحويل.
